Database Documentation

Generate beautiful, interactive, and easy-to-read documentation directly from your database schema in seconds.

Why DBNexus Docs?

Generate modern, interactive database documentation that saves you time and keeps your data perfectly organized.

Database As Code (DBML)

Define your database schema rapidly using the intuitive Database Markup Language (DBML). Keep your definitions structured, readable, and perfectly version-controlled.

Interactive Table Views

Instantly visualize your schema. Easily hide, highlight, and explore specific tables and their complex relationships without having to write or maintain complex SQL queries.

1-Click Markdown Export

Generate clean, portable Markdown documentation directly from your schema structure. Download it instantly to seamlessly integrate into your own wikis and internal knowledge bases.

How it works

1

Define schema using DBML

Write your database schema using our open-source Database Markup Language (DBML). It's simple, readable, and designed specifically for defining and documenting schemas.

2

Generate Documentation

DBNexus takes your DBML code and instantly generates a beautiful, interactive documentation site that you can view, share, and export as Markdown.

3

Interactive Table View

Explore your schema with an interactive table view that clearly displays relationships. You can easily hide or highlight specific tables to focus on what matters, and download your documentation as Markdown.

Table users {{ '{' }}
  id integer [primary key]
  username varchar
  created_at timestamp
{{ '}' }}

Table posts {{ '{' }}
  id integer [primary key]
  user_id integer
  body text
{{ '}' }}

// Relationships
Ref: posts.user_id > users.id

Interactive Data Dictionary

DBNexus automatically compiles your DBML schema into a searchable, living Data Dictionary. Bridge the gap between engineering and business by giving data scientists, backend engineers, and product managers a crystal-clear view of your data model.

Organized Grid Layout

View your tables in a beautifully structured grid. Instantly see columns, data types, primary/foreign keys, and relationships without writing complex SQL queries.

Instant Search & Filtering

Navigate massive schemas effortlessly. Use the side panel to search for specific tables, columns, or data types, and toggle their visibility on the fly.

Export to Markdown

Need to update your internal wiki? Export the entire data dictionary as a Markdown file with a single click and paste it into GitHub, Notion, or Confluence.
